# Pictures placed by hand

The pages were designed in Lovable, which keeps their pictures on its own
servers. When the agent serves the pages, it fetches each picture from Lovable
once and keeps a copy.

If a picture does not show at `http://localhost:3000` (the agent says so in its
terminal), save the picture in this folder under the name the agent mentions,
for example `tunisian_green_door.jpg`. A picture found here is used first and
needs no network.
